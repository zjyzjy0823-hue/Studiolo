# 任务：写一份「上手说明」，不要技术味

## 产出

写一个新文件：`docs/使用指南.md`

## 这是给谁看的

给**不搞技术的人**看（包括未来的自己）。目标是：拿到安装包的人照着做，5 分钟能用起来。

## 语气与风格（重要）

- 中文，口语，轻松一点，可以偶尔皮一下、开个小玩笑，但别油腻
- **禁止出现技术名词**：不要写 Tauri / Rust / Python / sidecar / WebSocket / JWT / 端口 / 进程 / 编译 / epoch / frp / AList / API Token 这类词
- 不要代码块，不要命令行
- 多用短句、表格、emoji 小标题
- 遇到需要解释的机制，用比喻（例如「钥匙串 = 系统替你保管密码的保险箱」）

## 必写的内容

### 1. 开头一句话
一句话说清这东西是干嘛的（个人数字控制台：记账、收藏、文件、和 AI 助手对话，手机上也能看）。

### 2. 安装（三个平台各一段）

| 平台 | 安装包 | 要点 |
|---|---|---|
| Mac | `Studiolo_0.9.9_x64.dmg` | 打开后把图标拖进 Applications；第一次打开如果提示"无法验证开发者"，**右键 → 打开**，或到「系统设置 → 隐私与安全性」点「仍要打开」 |
| Windows | `Studiolo_0.9.9_x64-setup.exe`（或 .msi） | 双击安装；首次运行 SmartScreen 蓝屏提示 → 「更多信息」→「仍要运行」 |
| Android | `Studiolo_0.9.9_universal.apk` | 允许"安装未知来源应用"；装完直接打开 |

三个包都是**未签名/自签名**的，所以系统会多问一句，属正常现象，不是病毒。

### 3. 第一次打开会看到什么

- 会弹一个「钥匙串」授权框：**点「始终允许」，输入一次开机密码**。解释成：系统保险箱要确认是你本人。
- 然后进入「今天」页面。

### 4. 五个场景（每个配一张图）

图片都在 `docs/images/` 下，用相对路径引用，例如 `![今天的仪表盘](./images/guide-today.png)`。

| 图片 | 内容 | 建议写的角度 |
|---|---|---|
| `guide-today.png` | 「今天」仪表盘：余额、系统与任务、数据资产、工作台状态、Token 用量、订阅额度 | 一打开就看到的全貌，像汽车仪表盘 |
| `guide-ledger.png` | 账本：支出/收入/结余、流水表、分类占比 | 记一笔账有多快，月底看分类 |
| `guide-agent.png` | Agent 对话页：左边会话列表、右边聊天区 | 和 AI 助手聊天、让它干活 |
| `guide-downloads.png` | 设置里的「下载记录」 | 下载过的东西都在这儿，大文件走高速通道 |
| `guide-pages.gif` | 动图：几秒内切换几个页面 | 放在"随便逛逛"那一节，展示切换很顺 |

### 5. 常见小问题（用问答形式，3–5 条）

- 弹钥匙串授权框 → 点始终允许，输一次密码，以后不再问
- 助手说"额度用完了" → 换个模型，或等额度恢复（界面上会写恢复时间）
- 左边显示"没有在线节点" → 那台电脑上的 Studiolo 没开着，打开它就行
- 手机上找不到某个会话 → 点右上角筛选，把"已归档"打开
- 下载的文件在哪 → 小文件在「下载」文件夹，大文件链接 24 小时有效

### 6. 结尾

一句话收尾 + 当前版本号 `0.9.9`。

## 硬性要求

- 全文 900–1400 字
- 至少 3 个表格、5 个二级标题、emoji 适量（别每行都有）
- 图片必须用相对路径 `./images/...`，并且每张图下面有一行小字说明
- **不要**写任何内部项目名（Nexa、Nexa-LumaDock、agent-node、Core Fleet 这类）
- **不要**编造截图里没有的功能
- 写完后自己通读一遍：如果出现一个技术名词，就换成人话

## 交付

只新增 `docs/使用指南.md` 一个文件，不要改别的。
