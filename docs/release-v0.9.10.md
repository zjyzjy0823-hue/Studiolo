# Studiolo v0.9.10 — 聊天可靠性 + 字号与下载修复

> ⚠️ 预发布（pre-release）。CI 全绿即发布；真机项（发送/插话、附件预览、下载打开、字号六档）已在 Android 真机逐项过表。

## 主要变化（自 v0.9.9）

### 发送与插话（可靠性）
- **点发送必定发出去**：删除「待发送」中间态，只有「已发送」与「发送失败 · 重试」两种结局
- **agent 运行中自动插话**：不再退回对话框等回合结束；服务端在运行中收到 `prompt.send` 也会降级为 steer 并回执
- **回执多键对账**：`requestId` → `commandId` → `(会话, 文本, 60s 窗)`，控制帧不再被流序号缓冲吞掉
- **失败消息可清理**：逐条 ✕ 删除 + 7 天自动清理 + 重试复用同一条，不再堆在会话最下面

### 会话界面
- **助手消息时间戳**（移动端常显，桌面 hover），工具步骤展开后显示 `HH:mm:ss`；历史缺数据时显示 `—` 而不是乱推算
- **工作步骤合并**：「工作步骤 · N 步」把同一回合的连续工具卡收成一张（旧版曾出现 9 张空壳卡）
- **附件缩略图**：剥离 `[附带文件]` 说明块，图片走 Core 预览接口渲染缩略图，其它文件显示芯片
- **运行中标志不残留**：回合结束 / 断线 / 回前台都会整会话对账，不再出现「任务早就结束了还挂着停止键」

### 字号
- **全局字号六档**（紧凑 0.8 / 小 0.9 / 标准 1.0 / 大 1.12 / 更大 1.25 / 特大 1.4），只影响文字，图标与间距不动
- 补齐设计系统层：`design/studiolo-redesign/*.css` 共 148 处 `font-size` 现在也跟随档位（此前正文字号锁死 14px）
- 仅本机保存，不参与同步

### 下载与打开
- 下载进度圆环（聊天页与下载页一致的流式读取）、完成后打勾、重进保留完成态
- 点击已下载文件调用系统「打开方式」；APK 直接进入系统安装器（补 `REQUEST_INSTALL_PACKAGES`，不再被 `Intent.createChooser` 拦掉）
- MediaStore 未索引时回退 FileProvider；文件已被移走则退回「可下载」状态
