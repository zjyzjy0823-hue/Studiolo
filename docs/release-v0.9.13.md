# Studiolo v0.9.13 — 更新入口视觉打磨

本版只改更新入口的视觉与交互，功能与 v0.9.12 一致。

## 更新入口（桌面右下角 / 手机设置页）

- 按钮从 32px 缩到 **24px**，与状态栏行高对齐，不再把状态栏撑高
- 亮色主题冷墨黑底 + 1px 内描边，暗色主题反白（深色图标），两种主题都不再像"贴上去的"
- 交互：hover 上浮 1px + 箭头旋转 18°、按下缩到 0.92、键盘 focus 双环，状态切换 180ms 过渡
- 五种状态动效：
  - 检查中：箭头匀速旋转
  - 发现新版：右上角 accent 圆点 + 2s 呼吸光环（hover 加快到 1s）
  - 下载中：conic 环形进度 + 悬停显示百分比气泡
  - 待重启：箭头换成 RotateCw + 轻微弹跳
  - 失败：红色外环 + 图标转红
- 弹层重做：260px、带指向按钮的小箭头、`scale+fade` 出现动画、说明支持多行、主次按钮（下载并安装 / 稍后）、打开时自动聚焦主按钮
- 手机端设置行改为胶囊状态，与设置页其它 chip 一致
- `prefers-reduced-motion` 下自动关闭旋转/光环/弹跳

## 已知说明

- 本版不含功能改动，v0.9.12 的应用内更新即可升级到本版
