# Studiolo v0.9.13 — 下载页 + 更新入口打磨

## 新增：桌面端「下载」页

- 左侧栏新增「下载」入口，独立的文件管理页（不再是跳设置页）
- 表格列：勾选 / 文件名 / 来源会话 / 大小 / 时间 / 状态 / 操作
- 顶部单行工具栏：搜索 → 类型筛选（全部/图片/文档/压缩包/安装包/其它，带计数）→ 时间范围 → 排序 → ⟳ 刷新 → 在文件夹中打开
- 行内操作：打开文件、在文件夹中显示、重新下载（外链）、删除记录
- 进行中的下载置顶并显示进度；失败项可重试；支持批量删除
- 空状态区分「还没有下载」与「筛选无结果」

## 更新入口视觉打磨（桌面右下角 / 手机设置页）

- 按钮 24px，与状态栏行高对齐，不再把状态栏撑高
- 亮色冷墨黑底 + 1px 内描边，暗色反白，两种主题都贴合
- 交互：hover 上浮 1px + 箭头旋转 18°、按下缩到 0.92、键盘 focus 双环
- 五态动效：检查中旋转 / 发现新版呼吸光环 / 下载中 conic 进度 + 百分比气泡 / 待重启弹跳 / 失败红环
- 弹层 260px、带指向箭头、主次按钮（下载并安装 / 稍后）
- 支持 `prefers-reduced-motion`

## 修复

- 桌面端补齐 `reveal_in_folder` 命令注册（此前只在 Android 注册，"在文件夹中显示"会报 command not found）

## 已知说明

- 桌面端首次启动或每次换构建后，macOS 会弹一次「访问钥匙串中的密钥」，点「始终允许」即可（WebKit + 自签名机制所致，换构建会再问一次）
- v0.9.12 可在应用内直接升级到本版
