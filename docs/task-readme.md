# 任务：写仓库首页 README

## 产出

新建 `README.md`（仓库根目录），替换原来那份技术文档（它已经归档到 `docs/README-技术版.md`，新 README 里给个链接指过去就行）。

## 读者与目标

进来的可能是朋友、同事，或者三个月后的自己。目标：**30 秒内知道这东西能干嘛，并且想点开看看**。

## 语气

- 中文，轻松、有梗、有画面感，像在跟人聊天
- 可以自嘲、可以打比方，但别油腻、别用烂梗
- **不要堆技术名词**：不写 Tauri / Rust / WebSocket / JWT / sidecar / API / 端口。
  需要提到"多设备"就说"家里那台 Mac 和公司那台 Windows 都能被同一个入口指挥"，别说架构
- 允许少量技术事实（比如"附件加密""聊天不落中心库"），但要用白话讲清楚"对用户意味着什么"

## 必写的结构

### 1. 开头（3 行以内）
一句话说清：这是一个把「记账 / 收藏 / 文件 / 和 AI 助手对话」装进一个窗口的私人控制台，电脑手机都能用。
配一句有画面感的 tagline。

### 2. 一张动图
先给个动图让人有直观感受：

```markdown
![页面切换](./docs/images/guide-pages.gif)
```

下面配一句小字说明。

### 3. 它能干什么（6 个左右，用小标题 + 两三句）
每条不要超过 4 行，尽量具体、有画面：

1. **今天**：一屏看完余额、待办、设备在线状态、AI 用量（配图 `./docs/images/guide-today.png`）
2. **账本**：记一笔只要三秒，月底自动按分类算账（配图 `./docs/images/guide-ledger.png`）
3. **和 AI 助手对话**：左边挑会话，右边直接派活；断网、切页面、重启都不丢消息（配图 `./docs/images/guide-agent.png`）
4. **多台电脑，一个入口**：家里 Mac、公司 Windows 上跑着助手，都能在这一个窗口里使唤
5. **文件和大文件**：小文件直接存本地，大文件走高速通道，链接 24 小时内有效（配图 `./docs/images/guide-downloads.png`）
6. **跨设备**：手机上看同一份账本和会话

### 4. 一张对比表：能解决什么烦恼

| 以前 | 现在 |
|---|---|
| ... | ... |

写 4 行左右，用生活化的痛点（比如"聊到一半断网，回来发现少了几条""手机上想接着电脑上的活"）。

### 5. 怎么装（简短）

一张表：macOS / Windows / Android 三个包名 + 一句话要点，然后一行指向详细版：

> 详细步骤（含截图）见 [使用指南](./docs/使用指南.md)

### 6. 结尾

一句收尾 + 当前版本 `0.9.9` + 一行链接到 [技术版文档](./docs/README-技术版.md)（写给想深挖的人）。

## 硬性要求

- 全文 600–1000 字，不超过 120 行
- 图片必须用相对路径，且**每张图下面有一行小字说明**
- 至少 2 个表格、5 个二级标题
- emoji 适量（标题前一个即可，别满屏）
- 不要编造功能：只能写上面列到的
- 不要出现真实金额、真实账号、真实人名
- 写完后通读：出现看不懂的词就换成人话

## 交付

只新增 `README.md` 一个文件。
