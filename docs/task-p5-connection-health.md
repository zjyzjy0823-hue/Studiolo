# 任务书：P5 —— 连接健康（心跳、判陈旧、换网探测、停止空转）

## 一、目标

1. 不再出现「老是显示重连」
2. 网络切换（WiFi ↔ 5G）后 5 秒内自动恢复，不闪屏
3. **停掉高频轮询**：Core 日志被 `GET /api/v1/sync/changes` 刷满（几秒一次、多个来源）

## 二、要做的（只改 `src/`）

### 1. 应用层心跳

在 Fleet WS 连接里（`src/stores/fleet.ts` / `src/services` 里现有的连接封装）：

- 每 **15 秒** 发一次应用层 ping（用现有 RPC 方法即可，优先 `gateway.ping`；若客户端没有该方法，用最小代价的只读 RPC，如 `session.list` 限 1 条）
- **60 秒**没有任何帧（含心跳回执）→ 判定陈旧 → 主动断开重连
- 心跳失败**不弹错误**，只推进重连状态机

### 2. 换网探测

- 监听 `online` / `offline` 事件与 `visibilitychange`（回到前台）
- 触发时先做一次 **5 秒超时**的活性探测；成功 → 什么都不显示；失败 → 才进入重连
- 「重连中」提示**仅在真的断开时出现**；恢复后不闪屏（现有 UI 文案保留，不改样式）

### 3. 停止空转轮询（重要）

排查并修复 `sync/changes` 被高频调用的来源（`src/services` 里的同步循环）：

- 正常空闲时**不得**持续轮询；改为事件驱动 + 兜底间隔 ≥ 30 秒
- 页面不可见（`document.hidden`）时暂停轮询
- 用可注入的定时器写测试断言「空闲 60 秒内调用次数 ≤ 3」

### 4. 不做的事

- 不改 Core / 节点 / `src-tauri/`
- 不改 legacy 同步模式的语义
- 不动 P10b 的翻页逻辑

## 三、测试（真跑并贴输出）

1. 心跳：15 秒定时触发（假时钟），60 秒无帧判定陈旧并触发重连
2. 换网：`online` 事件 → 5 秒内探测一次；成功不置「重连中」
3. 空转：空闲 60 秒内 `sync/changes` 调用 ≤ 3；`document.hidden` 时 0 次
4. 恢复后状态回 `online`，不重复触发
5. `node --test tests/` 全绿（现有 257 项 + 1 skip 保持）、`npx vue-tsc --noEmit` exit 0

只改 `src/` 与 `tests/`；不引入依赖；不 commit、不打包。
